2026-11-13，Windows 11 x64：11 项本地测试通过。仅运行只读检查、夹具解析与模拟部署；没有重新下载安装约 1 GB 主包，没有在当前电脑触发 UAC、执行真实部署或系统修复。

运行：`python test_installer.py`。首次全组有 10 项通过，另 1 项因测试将 WSH 管道输出误按 UTF-8 解码而失败；修正测试按系统 ANSI 回退后，仅重跑该项通过。产品代码没有因该测试修正而变化。

覆盖内容：

- 内置 19 项逻辑断言：版本、参数引用、包名/发布者/架构、依赖、外部实体拒绝与安装状态解析。
- 两个实际 BAT 入口、中文与特殊字符路径、参数顺序、只读检查不创建下载目录、中文帮助输出。
- 缓存复用及时间戳许可证复用；刷新时只请求两个官方地址，保留已有包和许可证。
- 仅下载模式从入口到结果，不检查管理员、不访问部署服务、不调用安装命令；下载调用使用本地替身，没有访问网络。
- 7 个模拟部署情形：首次、已安装、普通失败、组件错误两例、结果核验失败、需要重启；失败不误报成功、不执行自动修复。
- 真实 Windows curl 版本查询、子进程退出码和 tar 读取本地模拟 MSIX 清单；没有运行真实安装。
- ZIP 文件清单、脚本 ASCII/CRLF、逐文件 SHA-256 一致，无 PowerShell、自动修复或启动服务调用。

源码另通过 Node.js 语法检查。源码/脚本读取清单不等同签名核验，真实部署时由 Windows 校验 MSIX 签名。

已知限制：尚未在干净系统、Arm64 或禁用商店的云电脑上完整安装验证；不保证中断下载续传；脚本需要系统自带 WSH、curl、tar 和安装时的 DISM。安装与权限由 Windows 策略决定。离线下载完成不等于应用已安装、已启动或已登录。

最终发布包重建后复核文件清单与校验值；公开发布不包含原始系统日志、个人路径、离线许可证或 ChatGPT 应用本体。
